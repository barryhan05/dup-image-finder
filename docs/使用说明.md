# 使用说明

Find images with identical content but different filenames, and deal with them —
without ever uploading anything.

---

## 一、三种处理方式

打开程序后，第二块区域的「处理方式」三选一：

| 方式 | 源目录 | 产物 | 什么时候用 |
|---|---|---|---|
| **复制精简**（默认） | **完全不动**，只读取 | 新建的「精简版目录」 | 原图要留着，只想拿一份干净的副本去用 |
| **移动隔离** | 会减少文件 | 「隔离目录」，可一键还原 | 确认重复项可以挪走，想直接给原目录瘦身 |
| **只出报告** | 完全不动 | 只生成报告 | 先看看有多少重复，再决定怎么办 |

**三种方式都不会删除任何文件。**

---

## 二、基本流程

1. 双击 `DupScan.exe`
2. 「扫描目录」选要清理的文件夹（可递归子目录）
3. 第二行的输出目录会自动填好，想换位置就点「浏览」
4. 点 **开始处理**
5. 跑完点「打开报告」核对每一组

复制或移动之前会弹窗确认，确认后才动文件。

---

## 三、复制精简的结果长什么样

**默认保持原来的子目录结构**，能和原目录一一对照：

```
原目录/                          精简版/
  claude/教学楼1.jpg      →       claude/教学楼1.jpg
  claude2/教学楼1.jpg             claude/角落1.jpg
  img17.jpg                       ...
```

想让所有图片平铺在一个文件夹里，勾「全部放同一层」。
注意：不同子目录下的同名文件会被自动改名成 `xxx_2.jpg`，不会互相覆盖。

结果目录里会有 `manifest.csv`，记录每个副本对应哪个原文件，可用 Excel 打开。

---

## 四、同一组里保留哪一份

批量处理过的图库常见情况：同一张图有三个名字 —— `img17.jpg`、`教学楼1.jpg`、
`教学楼1(1).jpg`。默认规则按这个优先级挑：

1. **分辨率最高**
2. **文件体积最大**
3. **文件名信息量** ← `教学楼1.jpg` 会胜过 `img17.jpg`，因为后者是批量改名留下、没有语义的名字
4. 修改时间更早
5. 路径字典序

其他可选规则：

| 规则 | 说明 |
|---|---|
| 质量优先（默认） | 分辨率 → 体积 → 文件名 → 时间 |
| 文件最大 | 只看体积 |
| 分辨率最高 | 只看像素数 |
| 修改时间最早 | 保留最早的一版 |
| 路径最短 | 保留层级最浅的 |
| 路径字典序 | 结果可复现 |

---

## 五、选项

| 选项 | 说明 |
|---|---|
| **判定方式 · 精确 + 相似** | 默认。既抓改名的纯副本，也抓重新保存、压缩过的同一张图 |
| **判定方式 · 仅精确** | 只认字节完全一致。最快，零误判 |
| **相似阈值** | 默认 6。越大越宽松，也越容易误判。漏检多调到 8~10，误判多降到 4 |
| **校验 SHA256** | 复制完逐个核对哈希。更稳，但大图库会慢一些 |
| **全部放同一层** | 不保留子目录，所有图平铺 |

---

## 六、隔离之后想反悔

点界面右下角 **还原隔离…** → 选择隔离目录里的 `manifest.json`。

全部文件按原路径移回去，子目录结构一并恢复。原位置如果已有同名文件，
会自动改名成 `xxx_restored.jpg`，**不会覆盖**。空的组文件夹会被自动清掉。

---

## 七、注意

- **报告含真实文件路径和缩略图，等同于敏感数据本身，不要外发。**
- 「精简版目录」不能设在扫描目录**内部**，程序会拒绝——放在里面会让下次扫描
  把副本也扫进去，还违背了"原目录不动"。
- 杀毒软件可能报毒（未签名 exe 的常见误报），加白名单即可，
  或改用 `scripts/Find-DupImages.ps1`（零依赖，只做字节级比对）。
- 首次双击启动慢 3~5 秒，是单文件 exe 在解压，正常。
- 报告里的缩略图直接引用原图，**原图挪走后报告里就看不到图了**。

---

## 八、命令行

```bash
DupScan.exe -p "D:\图库"                                  # 只出报告
DupScan.exe -p "D:\图库" --collect                        # 复制精简
DupScan.exe -p "D:\图库" --collect --collect-to "D:\精简"   # 指定输出位置
DupScan.exe -p "D:\图库" --collect --flatten               # 平铺不建子目录
DupScan.exe -p "D:\图库" --isolate                        # 移动隔离
DupScan.exe -p "D:\图库" --isolate --dry-run               # 演练，不动文件
DupScan.exe --restore "隔离目录\manifest.json"              # 还原隔离

# 可选参数
--mode {both,exact}            判定档位，默认 both
--threshold 0-16               相似阈值，默认 6
--keep {best,largest,resolution,oldest,shortest,first}
--verify-hash                  复制后校验 SHA256
--title / --cover / --logo     报告定制
--open                         跑完自动打开报告
```
